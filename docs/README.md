# Документация и тестирование

| Файл | Что это |
|---|---|
| `Индивидуальный_проект_Тренажёр_английских_слов.docx` | Индивидуальный проект: требования, инструкция по разработке, руководство пользователя, тест-сценарий, тест-пакеты, тест-кейсы, результаты |
| `run_tests.py` | Автоматический прогон 44 тест-кейсов по окнам программы со снимками экрана |
| `results.json` | Фактические результаты прогона (используются в документе) |
| `данные.py` | Требования, тест-пакеты, тест-кейсы и дефекты в одном месте |
| `сборка_docx.py` | Сборка документа .docx из данных и результатов |
| `скриншоты/` | Снимки экрана, сделанные при прогоне |

## Как повторить тестирование

Из корня проекта:

```bash
pip install -r requirements.txt
python docs/run_tests.py
```

Скрипт создаёт временную пустую базу, нажимает кнопки так же, как пользователь, проверяет результат в окнах и в базе и печатает итог.

Итог прогона 26.11.2026: **42 из 44** тест-кейсов пройдено, автотесты 11 из 11.
Непройденные ТК-26 и ТК-44 — найденные дефекты ДФ-01 и ДФ-02 (описаны в разделе 7 документа).
